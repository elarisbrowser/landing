# Alpha tester onboarding

## Selecting and inviting testers

1. Review applications and select testers.
2. Send each selected tester a Discord friend request, then a personal server invite.
3. Assign the `Alpha Tester` role after they join.
4. If they do not see the Discord request, use their optional X handle as a backup contact route.
5. Keep each personal invite link private and send it only to its intended tester.

## Private channels

Start with these two private channels:

- `#alpha-start-here` — install instructions, known issues, and build links when builds are ready.
- `#alpha-feedback` — bug reports and tester discussion.

Pin this template in `#alpha-feedback`:

```text

```
